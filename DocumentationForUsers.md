# BruchinDB User Documentation

Live site: https://bruchindb.org

# What Is BruchinDB?

BruchinDB is a public web database for exploring seed beetle (Bruchinae) records compiled from Dr. Geoffrey Morse's research database. The site is intended for researchers, museum curators, natural resource managers, educators, students, and other users who need access to seed beetle taxonomy, specimen records, host plant associations, collection localities, and species images.

The public website is read-only. Users can search, browse, view maps, and submit proposed records or updates, but submitted information is reviewed by the database administrator (Dr. Morse) before it is added to the research database.

# Main Pages

# Search

Use the Search page to find seed beetle species and related records. The filter panel allows you to search by:

- Scientific name
- Tribe
- Country, province/state, or locality
- Host plant
- Species with available images

After selecting filters, click "Search" to update the results. Click "Reset" to clear filters and return to the default results view.

Search results appear as species cards. Select a species card to open that species' detail page.

The Search page also includes:

- Sort: order results by name A-Z, name Z-A, or tribe.
- Filters: collapse or reopen the filter sidebar.
- Recently Viewed: quickly return to species pages you have opened recently.
- Saved Queries: save a filtered search and reopen it later from the same browser.

Saved queries and recently viewed species are stored locally in your browser. They may not appear if you switch browsers, clear browser data, or use a different device.

# Species Detail Pages

A species page gives a more complete view of one selected species. Depending on available data, it may include:

- Taxonomic information
- Species images
- Related specimens
- Collection events
- Locality map
- Host plant associations

Some species may have more complete records than others. If no coordinates or images are available for a species, the relevant section may be empty or hidden.

# Specimen Detail Pages

Specimen pages show information for an individual specimen record when available. These pages may include:

- Specimen information
- Collection event information
- Host plant information
- Citation information
- Notes
- Images

Use the breadcrumb links near the top of the page to return to the related species page or search results.

# Map

Use the Map page to explore specimen localities geographically. The map displays specimen locality points and clustered markers where many records occur near each other.

You can filter map records by:

- Scientific name
- Tribe
- Country, province/state, or locality
- Minimum elevation
- Host plant
- Host plant family
- Image availability

Click "Search" to apply map filters. Click "Reset" to clear them.

Map interactions:

- Click a cluster to zoom into that area.
- Click an individual locality point to open matching results on the Search page.
- Use the bounding box button in the map controls to select a rectangular area. After drawing an area, click "View results" to open species found inside that area on the Search page.
- Use the clear bounding box button to remove the selected area.

# Submit Data

Use the Submit Data page to propose new records, images, or updates. Submissions are reviewed before being incorporated into the database.

The form allows contributors to provide:

- Photo files
- Latitude and longitude
- Location description
- Host plant name
- Host type, such as seed, pod, flower, or unknown
- Collector name
- Email address
- Collection date
- Additional notes
- Additional supporting files

When submitting data, provide as much detail as possible. Precise location, host plant, collection date, and collector information make records easier to verify.

After submitting, the page should show a confirmation message if the submission was received successfully. If there is an error, review the message shown on the page and try again later.

## Tips for Searching

- Start broad, then narrow your search with additional filters.
- If you are unsure of spelling, begin with a partial scientific name and use the suggestions when available.
- Use location filters when looking for records from a specific region.
- Use host plant filters when investigating beetle-plant associations.
- Enable image-only filtering when you need species records with available images.
- If no results appear, remove one or more filters and search again.

# Data Notes

BruchinDB records come from a scientific research database. Some fields may be incomplete, unavailable, or formatted differently depending on the source record.

Coordinates, localities, host plants, dates, and identifications should be interpreted as research data. If you plan to cite or use records for formal scientific work, verify important details and contact the project sponsor or database administrator when needed.

# Troubleshooting

If search results or maps do not load:

- Refresh the page.
- Check your internet connection.
- Try clearing filters and searching again.
- Wait a few minutes and retry if the database server or proxy is temporarily unavailable.

If images do not appear:

- Try refreshing the species or specimen page.
- Confirm that the species has image records available.
- Try a different browser if the issue persists.

If a submission fails:

- Make sure your email address is valid if you entered one.
- Try a smaller file or fewer attachments.
- Refresh the page and submit again.
- If the issue continues, contact the project team or database administrator.

# Privacy and Submissions

Information submitted through the Submit Data form may include contact information, collection details, and uploaded files. Submit only information that you are comfortable sharing with the project administrator for review.

Submissions do not automatically appear on the public site. They are reviewed for accuracy and consistency before any database changes are made.
